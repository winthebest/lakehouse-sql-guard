== 3/11  sqlguard leakage dbt: the leak, where it is, and a fix
   # The finding is attributed to the intermediate model, not to training_churn,
   # and replay over the snapshot history confirms the feature values differ.
   $ sqlguard leakage dbt --manifest build_ci/manifest.json --replay --catalog lakehouse --catalog-namespace raw --suggest-fix
    LEAKY         0.94  models/marts/training_churn.sql
        L4           orders is bounded by event time only; rows ingested after cutoff_ts (loaded_at) may leak in [orders]
                     in models/intermediate/int_customer_orders_7d.sql
        REPLAY       feature values differ from what was knowable at prediction time
                     in models/marts/training_churn.sql
        fix L4  [static_and_replay; semantics changed] orders (in models/intermediate/int_customer_orders_7d.sql): Bound loaded_at of orders strictly before labels.cutoff_ts in the join condition, so each prediction only sees facts that had already landed.
            caveat: rows may drop: it cannot be shown that only the bound changed: a JOINS sits above the values; a clause that reads values derived from orders may filter, limit or merge spine rows
        suggested change (formatting normalized; the file is not modified; shown against the compiled query with upstream models inlined):
    --- a/models/intermediate/int_customer_orders_7d.sql
    +++ b/models/intermediate/int_customer_orders_7d.sql (suggested)
    @@ -9,6 +9,7 @@
         ON orders.user_id = labels.customer_id
         AND orders.ordered_at < labels.cutoff_ts
         AND orders.ordered_at >= labels.cutoff_ts - INTERVAL '7' DAY
    +    AND orders.loaded_at < labels.cutoff_ts
       GROUP BY
         labels.customer_id,
         labels.cutoff_ts
    replay: MISMATCH - 50 of 127 rows differ at 4 prediction dates (amount_7d, orders_7d)

== 4/11  Apply the suggested fix, rebuild, check again
   # The suggested change adds one line to the intermediate model's join:
   $ diff -u --label models/intermediate/int_customer_orders_7d.sql --label suggested models/intermediate/int_customer_orders_7d.sql fix/int_customer_orders_7d.sql
    --- models/intermediate/int_customer_orders_7d.sql
    +++ suggested
    @@ -10,6 +10,7 @@
     left join {{ source('raw', 'orders') }} as orders
         on orders.user_id = labels.customer_id
         and orders.ordered_at < labels.cutoff_ts
    +    and orders.loaded_at < labels.cutoff_ts
         and orders.ordered_at >= labels.cutoff_ts - interval 7 day

     group by labels.customer_id, labels.cutoff_ts
